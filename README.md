# YouTube Study Focus 🎯

## 📌 About the Project
YouTube Study Focus is a Chrome browser extension designed to help students stay focused while studying on YouTube.

It reduces distractions by hiding comments, recommended videos, and YouTube Shorts while allowing users to watch their selected videos.

## ✨ Features
- Hide distracting YouTube comments.
- Hide recommended videos.
- Hide YouTube Shorts.
- Keep video playback available.
- Simple popup interface.
- Lightweight Chrome extension.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Chrome Extension Manifest V3

## ⚙️ Installation

1. Download or clone this repository.
2. Open Google Chrome.
3. Navigate to `chrome://extensions/`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the project folder.
7. The extension will be added to Chrome.

## 🚀 How to Use

1. Open YouTube.
2. Click the YouTube Study Focus extension icon.
3. Use the available popup controls.
4. Enjoy a cleaner YouTube experience with fewer distractions.

## 🎯 Project Objective
The main objective is to create a distraction-free YouTube environment that helps students improve concentration and productivity during study sessions.
